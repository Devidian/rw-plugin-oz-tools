# OZ Tools 0.29.1

- Open **Privacy** from the plugin shortcut menu or use `/ozt privacy`. Each active external purpose has its own tab, and login reminders point to the new command.
- In-game Discord chat uses your permission to send and receive messages between the game and Discord. You can use it without a Discord account or Discord server membership.

Requires Java 25 and Rising World PluginAPI 0.9.3.2.
