# OZ Tools 0.28.3

- Fix the central `logLevel` setting so it filters messages from all plugins using `OZLogger`, including during early startup and when `logInternal=true`.
- Apply changes to `logLevel` when Tools settings are reloaded. Warnings and errors remain visible at `WARN`.

Existing world settings and data remain in place. Direct game-server and `System.out`/`System.err` messages are outside this filter. Requires Java 25 and Rising World PluginAPI 0.9.3.2.
