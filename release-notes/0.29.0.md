# OZ Tools 0.29.0

- Players can grant or revoke each external data purpose independently in the External Data Processing tab.
- Login displays one notice for outstanding choices. Server administrators can opt into a warning for players who declined.
- Server administrators can review declined choices in the Tools shortcut menu.
- Administrators can enable the OZ WebSocket and native web route switches independently. Both default to off.

Update OZ Tools before the other OZ plugins in this release wave. Requires Java 25 and Rising World PluginAPI 0.9.3.2.
