# OZ Tools 0.30.0

- Cached SQLite stores flush pending changes before closing. Failed flushes remain visible to the caller and pending changes can be retried.
- Plugins can register menus and settings, data and admin panels with cleanup scoped to the current provider. Retired panels and stale menu actions are removed on reload. Existing registration methods remain available.
- Player-triggered plugin installation and updates require admin permission.
- Plugins can reuse Tools to copy their own packaged area permission templates. Existing local files are preserved unless the caller explicitly requests an overwrite.

Requires Java 25 and Rising World PluginAPI 0.9.3.2. Install this Tools version before upgrading any plugin that uses the new scoped registrations or shared permission copier.
